# Política de privacidad

Fecha de entrada en vigor: 4 de octubre de 2026. Esta traducción es solo informativa; en caso de discrepancia, prevalece la versión en inglés.

Esta política cubre el sitio web lollipopkit.com y las aplicaciones publicadas por lollipopkit. Una aplicación que tenga su propia política de privacidad, indicada en [Políticas de privacidad de las aplicaciones](#app-privacy-policies), se describe allí por completo; esa política prevalece para la aplicación.

## Este sitio web

- lollipopkit.com es un sitio estático. El sitio en sí no establece cookies ni contiene analíticas, publicidad ni seguimiento.
- El idioma que eliges se guarda en el almacenamiento local de tu navegador y nunca se envía a ningún sitio.
- El sitio está alojado en Cloudflare Pages. Cloudflare procesa datos de las solicitudes, como tu dirección IP y el agente de usuario del navegador, para servir y proteger el sitio, según se describe en la [política de privacidad de Cloudflare](https://www.cloudflare.com/privacypolicy/).

## Datos de usuario de Google

Las siguientes aplicaciones de lollipopkit acceden a datos de usuario de Google mediante las API de Google:

- **MFuse** (macOS) solicita `https://www.googleapis.com/auth/drive` para montar tu Google Drive en Finder, y lee el nombre y la dirección de correo de tu cuenta de Google para identificar la conexión. Todos estos datos se procesan únicamente en tu Mac. Detalles: [política de privacidad de MFuse](https://mfuse.lollipopkit.com/privacy.html).

Para cada aplicación indicada arriba, lollipopkit:

- usa los datos de usuario de Google solo para ofrecer las funciones que el usuario solicita en esa aplicación;
- no transfiere datos de usuario de Google a lollipopkit ni a terceros;
- no usa datos de usuario de Google para publicidad y no los vende;
- no permite que ninguna persona lea datos de usuario de Google;
- no usa datos de usuario de Google para desarrollar, mejorar o entrenar modelos generalizados o no personalizados de IA o aprendizaje automático.

El uso y la transferencia por parte de estas aplicaciones de la información recibida de las API de Google cumplen la [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), incluidos los requisitos de Uso limitado. Ninguna otra aplicación de lollipopkit accede a datos de usuario de Google; una aplicación que lo haga en el futuro se indicará aquí antes de solicitar acceso.

Puedes revocar el acceso de una aplicación a tu cuenta de Google en cualquier momento en [myaccount.google.com/connections](https://myaccount.google.com/connections).
